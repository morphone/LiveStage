## 🔧 Configuration Rapide YouTube

1. **Google Cloud Console** (5 min)
   - Créer projet → Activer YouTube API → Obtenir Client ID

2. **Xcode** (2 min)
   - Ajouter permissions Info.plist
   - Configurer Client ID

3. **Test** (1 min)
   - Lancer l'app → Se connecter → Créer un stream !

**Détails complets** → Lire QUICKSTART.md
